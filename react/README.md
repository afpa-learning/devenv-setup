# Descriptif

Vous trouverez ci-dessous des procédures diverses vous permettant de :
1. créer un projet `React` avec les outils de développement fournis par `Vite`
2. créer un projet `NextJS`

## Projet React

Création d'un projet avec `Vite` :
```sh
npm create vite@latest <nom-applicaction> -- --template react
```

## Projet NextJS

Création d'un projet :
```sh
npx create-next-app@latest
```
